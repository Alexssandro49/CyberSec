
# Projeto de Auditoria

Template de projeto desenvolvido utilizando SQL, .NET 10 e React, com o objetivo de fornecer uma base para aplicações voltadas à realização de auditorias de segurança da informação.  

A aplicação foi projetada para auxiliar processos de auditoria relacionados às normas ISO/IEC 27001 e ISO/IEC 27701, permitindo a organização, gerenciamento e acompanhamento de requisitos, controles e avaliações de conformidade.  

O projeto busca oferecer uma estrutura inicial moderna e escalável para desenvolvimento de sistemas de auditoria, utilizando tecnologias atuais tanto no front-end quanto no back-end.

----

# Instalação e Configuração

Certifique-se de possuir os seguintes pré-requisitos instalados em sua máquina:

- Node.js
- Banco de Dados SQL
- .NET 10 SDK

---

# Clonando o Projeto

Clone este repositório utilizando o comando:

```bash
git clone <https://github.com/Alexssandro49/CyberSec.git>
```
---

# Front-end

Acesse a pasta do front-end:

```bash
cd dashboard
```

Instale as dependências do projeto:

```bash
npm install
```

Caso seja necessário, instale também as dependências abaixo:

```bash
npm install react-router-dom
npm install tailwindcss @tailwindcss/vite
npm install recharts
```

Execute o servidor de desenvolvimento:

```bash
npm run dev
```

O front-end estará disponível no endereço informado pelo terminal após a execução.

---

# Back-end

Acesse a pasta da API:

```bash
cd api
```

Execute a aplicação:

```bash
dotnet run
```

A API será iniciada no endereço informado pelo terminal.
